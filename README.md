# Simple Client-Side Image Editor

A lightweight, fully client-side image editor built with plain HTML, CSS, and JavaScript. You can paste, upload, or enter a URL to load an image, apply basic edits, crop, and save; all in the browser, with no backend.

**Live on:** [https://image-editor.dutl.uk](https://image-editor.dutl.uk)

---

## Features

* Load images by pasting, uploading, or providing a URL
* Adjust hue, saturation, contrast, and brightness
* Rotate and crop images
* Clear crop selection at any time
* Save the edited image in full resolution
* Fixed-size canvas for consistent display
* Fully client-side, no dependencies
